# Domain Onboarding Checklist

## Domain Pool

- Add domains to the domain inventory.
- Confirm status is active when ready.
- Confirm tier assignment.
- Confirm priority and health score.

## DNS Readiness

Future DNS verification should confirm MX, SPF, DKIM, and provider-specific inbound settings.

## Provider Mapping

Map each domain to the enabled inbound provider before exposing it to users.

## Safety

Keep fallback domains configured until the new domain has passed provider and inbox flow validation.
