# v1.1 Delegated Administration Model

## Scope

This document specifies future delegated administration only. STEP72 does not implement delegated admin.

## Future Roles

- Organization Owner: final authority over organization and ownership changes.
- Organization Admin: daily organization administration.
- Workspace Admin: workspace-scoped administration.
- Team Lead: team-scoped management.
- Security Reviewer: security and privileged access review.
- Compliance Reviewer: compliance and audit evidence review.
- Billing Reviewer: billing and cost visibility review.
- Auditor: read-only audit evidence access.
- Support Operator: scoped support access with reason and expiry.
- Guest: restricted explicit access only.

## Delegation Requirements

- Delegation should be scoped.
- Delegation should have an owner.
- Temporary delegation should expire.
- Sensitive delegation should require approval.
- Delegation removal should be auditable.
