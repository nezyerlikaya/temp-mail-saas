# v1.1 Enterprise SSO Specification

## Scope

This document is planning-only. STEP70 does not implement SAML, OIDC, OAuth providers, callbacks, token exchange, metadata storage, or identity provider configuration.

## Future Protocols

### SAML 2.0

Useful for established enterprise identity providers and procurement requirements.

### OpenID Connect

Useful for modern identity provider integration with claims-based login.

### OAuth Federation

Useful for delegated identity flows where appropriate, but should not replace authorization governance.

## Future Identity Providers

Examples:

- Microsoft Entra ID
- Okta
- Google Workspace

## Support Model

Future support should be per organization and include:

- Provider configuration
- Metadata or issuer management
- Claim mapping
- Group mapping
- Safe rollback
- Audit readiness

## Non-Goals

- No real SSO setup in STEP70
- No MFA implementation
- No auth redesign
- No user model redesign
