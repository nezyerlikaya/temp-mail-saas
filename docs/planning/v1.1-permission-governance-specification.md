# v1.1 Permission Governance Specification

## Scope

This document specifies future permission governance only. STEP72 does not change the current RBAC or permission system.

## Permission Types

- Direct Permission
- Role Permission
- Inherited Permission
- Delegated Permission
- Temporary Permission
- Emergency Permission

## Permission Lifecycle

Future states:

- Requested
- Approved
- Assigned
- Active
- Expiring
- Revoked
- Archived

## Permission Certification

Future review cadences:

- Monthly Review
- Quarterly Review
- Annual Review
- Event Driven Review
- High-Risk Review

## Authorization Audit Events

- Permission Request
- Permission Approval
- Permission Assignment
- Permission Revocation
- Delegation Grant
- Delegation Removal
- Emergency Access Usage
- Break Glass Usage
- Service Access Change
- Access Certification
