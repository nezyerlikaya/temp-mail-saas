# v1.1 Session and Device Governance

## Scope

This document specifies future session and device governance only. STEP70 does not implement MFA, device registration, session revocation, or high-risk detection.

## Session Governance

- Session Ownership
- Session Policies
- Session Revocation
- Concurrent Session Limits
- Session Review
- High-Risk Session Detection

High-risk signals may include unfamiliar device, location change, impossible travel, stale privileged sessions, and recent role changes.

## Device Governance

Future device states:

- Registered Device
- Trusted Device
- Managed Device
- Unmanaged Device
- Risky Device
- Revoked Device

## MFA Governance

Future MFA methods:

- TOTP
- Security Keys
- Passkeys
- Backup Codes
- Risk-Based MFA

No MFA system is implemented in STEP70.
