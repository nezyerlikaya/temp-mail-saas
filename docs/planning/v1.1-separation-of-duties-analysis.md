# v1.1 Separation of Duties Analysis

## Scope

This document specifies future separation-of-duties analysis only. STEP72 does not implement enforcement.

## Separation Pairs

### Security vs Billing

Security reviewers should not silently change billing ownership.

### Security vs Compliance

Security operators should not self-certify compliance evidence.

### Auditor vs Administrator

Auditors should not mutate systems they audit.

### Approver vs Requester

Requesters should not approve their own access.

### Governance vs Operations

Governance policy ownership should be separate from routine operations.

- User Access Review
