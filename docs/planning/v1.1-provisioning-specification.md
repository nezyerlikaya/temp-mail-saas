# v1.1 Provisioning Specification

## Scope

STEP71 is specification-only. It does not implement SCIM, SAML, OIDC, user model changes, auth changes, permission changes, billing changes, migrations, queues, events, or data writes.

## Provisioning Domains

### Identity Provisioning

Future lifecycle for creating, activating, suspending, disabling, and archiving identities.

### Membership Provisioning

Future lifecycle for assigning users to organizations, workspaces, teams, and roles.

### Organization Provisioning

Future lifecycle for onboarding and configuring enterprise organizations.

### Workspace Provisioning

Future lifecycle for creating and governing workspace boundaries.

### Team Provisioning

Future lifecycle for creating and governing teams.

### API Identity Provisioning

Future lifecycle for user, organization, workspace, and service API identities.

## Future Automation Readiness

- Auto-Provisioning
- Auto-Deprovisioning
- Lifecycle Workflows
- Approval Workflows
- Access Expiration Workflows
- Compliance Workflows

No workflow execution is implemented in STEP71.
