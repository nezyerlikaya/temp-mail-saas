# v1.1 Lifecycle Control Specification

## Scope

This document specifies future lifecycle governance only. STEP71 does not implement lifecycle storage, queues, automation, events, or permissions.

## Access Lifecycle Governance

- Access Request
- Access Approval
- Access Assignment
- Access Certification
- Access Revocation
- Access Expiration
- Emergency Access

## Workspace Lifecycle

Future states:

- Draft
- Active
- Suspended
- Archived
- Deleted

## Team Lifecycle

Future states:

- Proposed
- Active
- Merged
- Suspended
- Archived

## Membership Governance

- Invitation Governance
- Approval Governance
- Role Transition Governance
- Suspension Governance
- Removal Governance

## Lifecycle Audit Events

- Invitation
- Acceptance
- Provisioning
- Role Change
- Team Change
- Workspace Change
- Suspension
- Revocation
- Offboarding
- Organization Closure
