# v1.1 Risk, Audit, and Incident Governance

## Risk Management Model

Risk categories:

- Identity Risk
- Access Risk
- Data Risk
- API Risk
- Abuse Risk
- Billing Risk
- Operational Risk
- Compliance Risk

Each future risk record should include detection signal, severity, suggested response, and audit trail requirement.

## Audit Readiness Specification

Future audit trails should cover:

- Login and security events
- Role changes
- Access grants
- Access revocations
- Data exports
- Data deletion requests
- Policy changes
- Billing ownership changes
- API key lifecycle
- Organization setting changes
- Emergency access usage

Future audit fields:

- Who
- What
- When
- Where
- Before/after snapshot
- Reason
- Correlation id
- Retention class

## Incident Governance Specification

Incident types:

- Security Incident
- Abuse Incident
- Data Incident
- API Incident
- Billing Incident
- Provider Incident

Lifecycle:

1. Detected
2. Triaged
3. Contained
4. Investigated
5. Resolved
6. Reported
7. Archived

## Data Retention Governance

Temp Mail SaaS data categories:

- Ephemeral Mail Data
- User Account Data
- Organization Data
- Audit Logs
- Security Events
- Billing Metadata
- API Logs

Each future retention policy should define retention class, deletion eligibility, export eligibility, audit requirement, and privacy risk.
