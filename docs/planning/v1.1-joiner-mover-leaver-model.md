# v1.1 Joiner, Mover, Leaver Model

## Scope

This document specifies enterprise lifecycle planning only. It does not create users, memberships, roles, teams, or organizations.

## Joiner

New user onboarding.

States:

- Invited
- Pending
- Activated
- Onboarded

## Mover

Role, team, workspace, or responsibility transition.

States:

- Requested
- Approved
- Transitioned
- Validated

## Leaver

Departing user or access removal lifecycle.

States:

- Scheduled
- Suspended
- Revoked
- Archived

## Controls

- Joiners should receive least-privilege access.
- Movers should include old access review and new access approval.
- Leavers should revoke access before archival.
- Emergency or temporary access should expire automatically in future implementation.
