# v1.1 Access Boundary Specification

## Scope

This document defines future access boundaries only.

| Boundary | Ownership | Visibility | Control Scope | Escalation Path |
| --- | --- | --- | --- | --- |
| Personal Boundary | User | Owner | Personal resources | Support review |
| Organization Boundary | Organization | Owner and admins | Organization resources | Organization owner |
| Workspace Boundary | Workspace | Workspace admins and scoped members | Workspace resources | Organization admin |
| Team Boundary | Team | Team leads and scoped members | Team resources | Workspace admin |
| Resource Boundary | Resource owner | Policy-scoped roles | Single resource | Resource owner |
| Administrative Boundary | Platform or organization | Admins only | Administration | Security reviewer |
| Audit Boundary | Organization or platform | Audit roles | Audit evidence | Compliance reviewer |

## Guardrails

- Visibility should be narrower than ownership.
- Escalation paths must be auditable.
- Administrative and audit boundaries should not silently overlap.
- Emergency boundary crossing should expire.
